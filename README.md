# food-budget

A personal web app — installable as a PWA — for tracking grocery spending and nutrition at the item level.

## Features

- **Pantry** — maintain a product list with nutrition info (per 100g)
- **Purchase log** — record what you bought, where, how much, and at what price
- **Dashboard** — weekly and monthly spend breakdowns by product and store
- Designed to extend beyond food to broader spending categories later

## Stack

| Layer | Tech | Host |
|-------|------|------|
| Backend | FastAPI (Python) | Render |
| Frontend | HTML / JS | Vercel |
| Database | PostgreSQL | Supabase |
